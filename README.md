# Customer\_Data\_Analysis



Welcome to my \*\*first Data Analytics project!\*\* 🎉



This project was built using \*\*Python\*\* and its core data analysis libraries, including \*\*Pandas\*\*, \*\*Matplotlib\*\*, and \*\*Seaborn\*\*. The objective of this analysis is to explore customer purchasing behavior and generate actionable business insights using the \*\*RFM (Recency, Frequency, Monetary) Segmentation\*\* technique.



\##  Project Highlights



\* Performed data cleaning and preprocessing to prepare the dataset for analysis.

\* Conducted \*\*RFM Segmentation\*\* to classify customers based on their purchasing patterns.

\* Analyzed customer performance and identified key customer segments.

\* Generated insights into \*\*revenue contribution\*\*, customer value, and overall business performance.

\* Created clear and informative visualizations to effectively communicate the findings.



\## Technologies Used



\* Python

\* Pandas

\* Matplotlib

\* Seaborn

\* Jupyter Notebook
